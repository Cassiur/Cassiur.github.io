📚 学习资料导航

📌 本文持续更新。所有推荐均基于实际使用体验，不收广告费。博客全文导航请看 博客内容导航。

一、Java 后端学习路线总览

推荐顺序：Java 基础 → JVM → 并发 → Spring → MySQL → Redis → 消息队列 → Elasticsearch → Docker/K8s → 系统设计

每个阶段先看书打底 → 再刷题巩固 → 再看源码进阶。

二、必读书单

Java 核心

书名 推荐理由 难度
《Java 编程思想》（第4版） Java 入门经典，打基础用 ⭐⭐⭐
《Effective Java》（第3版） 进阶必读，条款式写法很适合面试答题 ⭐⭐⭐⭐
《深入理解 Java 虚拟机》（第3版·周志明） JVM 圣经，国内最权威 ⭐⭐⭐⭐⭐
《Java 并发编程实战》（Brian Goetz） 并发圣经，Happens-Before 讲透了 ⭐⭐⭐⭐⭐
《Java 并发编程的艺术》（方腾飞） 更适合中文读者，源码分析到位 ⭐⭐⭐⭐

数据库 & 中间件

书名 推荐理由 难度
《MySQL 技术内幕：InnoDB 存储引擎》（第2版） InnoDB 原理最权威，面试必备 ⭐⭐⭐⭐⭐
《高性能 MySQL》（第4版） 实战调优，索引优化讲得最清楚 ⭐⭐⭐⭐
《Redis 设计与实现》（黄健宏） Redis 源码级别讲解，SDS/跳表/字典全覆盖 ⭐⭐⭐⭐
《Kafka 权威指南》（第2版） Kafka 最系统的书，读完足够应对 80% 面试 ⭐⭐⭐⭐

系统设计 & 架构

书名 推荐理由 难度
《数据密集型应用系统设计》（DDIA） 系统设计天花板，必读 ⭐⭐⭐⭐⭐
《凤凰架构》（周志明） 国内最好的微服务架构书，免费在线阅读 ⭐⭐⭐⭐
《设计模式》（GoF） 23种设计模式，结合 Spring 源码看效果翻倍 ⭐⭐⭐

AI & 大模型工程

书名 / 资料 推荐理由
《大模型应用开发：动手做 AI Agent》 RAG + Agent 工程实践，贴近实际
LangChain / LlamaIndex 官方文档 框架文档即教程
Anthropic Cookbook（GitHub） Claude API 最佳实践示例

UP主 / 课程 内容 推荐指数

尚硅谷 · JVM 精讲（宋红康） JVM 最好的中文课程，配套《深入理解 JVM》看 ⭐⭐⭐⭐⭐

付费课程（值得买）

平台 课程 说明
极客时间 《MySQL 实战 45 讲》（丁奇） MySQL 最值得买的专栏，每篇都是精华
极客时间 《Java 并发编程实战》（王宝令） 源码级别讲并发，比书友好
极客时间 《Elasticsearch 核心技术与实战》 ES 最系统的实战课
慕课网 Spring Boot 企业级开发 项目实战向，简历项目参考

四、刷题平台

算法刷题

平台 推荐用法
LeetCode（力扣） 主刷平台，按 Hot 100 + 剑指 Offer 顺序刷
牛客网 · 算法专项 校招真题多，Java 输入输出题型更贴近笔试
LeetCode 题解（labuladong） 框架思路讲得最好，推荐配合刷题

推荐刷题顺序：

  1. 数组 / 双指针 / 滑动窗口（20题打底）
  2. 链表 / 栈 / 队列（20题）
  3. 二叉树（BFS/DFS，30题）
  4. 动态规划（背包、LCS、LIS，40题）
  5. 图论（DFS/BFS/并查集，20题）

面试八股刷题

平台 特点
JavaGuide（javaguide.cn） 最全面的 Java 面试手册，每道题都有详细解析
小林 Coding（xiaolincoding.com） 图解系列，MySQL / Redis / 网络 / OS 讲得极好
CS-Notes（GitHub: CyC2018） 经典，覆盖面广，适合快速复习
Java 全栈知识体系（pdai.tech） 体系化，深度够
牛客网 · 面试题库 分公司 / 分岗位，真实面经多

五、技术博客 & 网站

必看参考手册

网站 用途
Spring 官方文档（docs.spring.io） Spring / Spring Boot / Spring Cloud 第一手资料
Baeldung（baeldung.com） Java 生态最好的英文教程站，每篇都有代码
美团技术团队（tech.meituan.com） 工业级实战经验，Java 性能优化必看
阿里中间件博客 分布式系统深度文章
InfoQ 中文站 架构设计趋势，开阔视野
GitHub Trending 每天看热门开源项目，保持技术敏感度

大模型 / AI 工程

网站 用途
Anthropic 文档（docs.anthropic.com） Claude API，Prompt 工程最佳实践
LangChain 文档（python.langchain.com） RAG / Agent 框架
HuggingFace（huggingface.co） 模型 Hub，论文 + 代码
Arxiv（arxiv.org/list/cs.AI） 最新论文，RAG / Agent 相关搜 2404+

七、实用工具
