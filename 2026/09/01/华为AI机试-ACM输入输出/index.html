九、快速参考表⭐

输入格式 代码
单个整数 n = int(input())
空格分隔整数 nums = list(map(int, input().split()))
逗号分隔 nums = list(map(int, input().split(',')))
多个变量 a, b, c = map(int, input().split())
矩阵（n行） [list(map(int, input().split())) for _ in range(n)]
读到EOF for line in sys.stdin: ...
浮点数 nums = list(map(float, input().split()))
字符串 s = input().strip()
输出格式 代码
单个值 print(result)
空格分隔 print(' '.join(map(str, nums))) 或 print(*nums)
每个一行 print('\n'.join(map(str, nums)))
保留2位小数 print(f"{x:.2f}")
Yes/No print("Yes" if cond else "No")
矩阵按行 for row in matrix: print(*row)
