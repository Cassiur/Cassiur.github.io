华为AI机试选择题知识点大全（150分必背）

一、激活函数（高频考点⭐⭐⭐⭐⭐）

1. ReLU（Rectified Linear Unit）

优点：

  • ✅ 计算简单，训练速度快
  • ✅ 缓解梯度消失问题
  • ✅ 引入稀疏性（部分神经元输出0）

缺点：

  • ❌ Dead ReLU问题：负值输入导致梯度为0，神经元”死亡”
  • ❌ 输出不以0为中心

应对Dead ReLU：

  • 使用较小的学习率
  • 使用Leaky ReLU变体
  • 合理初始化权重

2. Leaky ReLU

优点：

  • ✅ 解决Dead ReLU问题（负值有小梯度）
  • ✅ 保留ReLU的计算优势

3. PReLU（Parametric ReLU）

特点：

  • α作为参数通过反向传播学习
  • 更灵活，但参数量增加

4. ELU（Exponential Linear Unit）

优点：

  • ✅ 输出均值接近0，加速收敛
  • ✅ 负值饱和区域产生对噪声的鲁棒性

缺点：

  • ❌ 计算exp较慢

5. GELU（Gaussian Error Linear Unit）⭐大模型常用

特点：

  • Transformer和BERT中的标准激活函数
  • 平滑的非线性
  • 考虑输入的概率分布

6. Sigmoid

优点：

  • ✅ 输出范围(0,1)，适合概率输出
  • ✅ 平滑可导

缺点：

  • ❌ 梯度消失严重（两端梯度接近0）
  • ❌ 输出不以0为中心
  • ❌ 计算exp较慢

应用场景：

  • 二分类输出层
  • 门控机制（LSTM的门）

7. Tanh（双曲正切）

优点：

  • ✅ 输出以0为中心（比Sigmoid好）
  • ✅ 梯度比Sigmoid大

缺点：

  • ❌ 仍有梯度消失问题
  • ❌ 计算复杂

8. Softmax（多分类输出层）

特点：

  • 输出总和为1，表示概率分布
  • 多分类任务的标准输出激活函数
  • 常与交叉熵损失配合

9. Swish（自门控激活函数）

特点：

  • Google提出，性能优于ReLU
  • 平滑、非单调
  • 计算成本略高

二、神经元死亡问题（Dead Neuron）⭐⭐⭐⭐

什么是神经元死亡？

当使用ReLU激活函数时，如果神经元的输入持续为负，则：

  • 激活值恒为0
  • 梯度恒为0
  • 权重无法更新
  • 神经元”死亡”，永久失效

产生原因

  1. 学习率过大：权重更新幅度过大，导致输入偏移到负区域
  2. 权重初始化不当：初始权重使大量神经元输出负值
  3. 数据分布问题：输入数据负值过多

检测方法

解决方案

  1. 使用Leaky ReLU/PReLU/ELU：负区域保留小梯度
  2. 降低学习率：避免权重剧烈变化
  3. Batch Normalization：规范化输入分布
  4. He初始化：针对ReLU的权重初始化方法
  5. 梯度裁剪：防止梯度爆炸导致的权重突变

三、Transformer架构（超高频⭐⭐⭐⭐⭐）

1. Self-Attention机制

计算公式：

时间复杂度：

  • 序列长度n，特征维度d
  • O(n²d)：主要瓶颈在QK^T矩阵乘法

空间复杂度：

  • O(n²)：存储注意力权重矩阵

2. Multi-Head Attention

公式：

参数量：

  • 假设输入维度d_model，h个头
  • 每个头的维度：d_k = d_model / h
  • W_Q, W_K, W_V: 3 × d_model × d_model
  • W_O: d_model × d_model
  • 总计：4d_model²

优点：

  • 多个子空间捕获不同关系
  • 增强模型表达能力

可学习位置编码：

结构：

四、KV Cache压缩技术⭐⭐⭐⭐

什么是KV Cache？

在自回归生成时，缓存所有历史token的Key和Value矩阵，避免重复计算。

内存占用：

压缩方法

1. Multi-Query Attention (MQA)

  • 所有head共享一个Key和Value
  • 减少KV Cache到1/h
  • Meta的LLaMA使用

2. Grouped-Query Attention (GQA)

  • 多个head共享一组KV
  • 介于MHA和MQA之间
  • LLaMA 2使用

3. 量化压缩

  • KV Cache量化到INT8/INT4
  • 减少50%-75%内存
  • 轻微精度损失

4. 滑动窗口 (Sliding Window)

  • 只保留最近N个token的KV
  • 适合长文本生成
  • Mistral使用2048窗口

5. PagedAttention

  • 分页管理KV Cache
  • 类似操作系统虚拟内存
  • vLLM框架核心技术

效果：

INT4量化

  • 需要更精细的校准

FP16混合精度

  • 训练常用
  • 减少50%内存
  • 几乎无精度损失

六、优化器对比⭐⭐⭐⭐

1. SGD (Stochastic Gradient Descent)

优点：

  • 简单高效
  • 收敛稳定

缺点：

  • 学习率难调
  • 容易陷入局部最优

2. SGD with Momentum

优点：

  • 加速收敛
  • 减少震荡

3. Adam (Adaptive Moment Estimation)⭐最常用

超参数：

  • β1 = 0.9（一阶动量）
  • β2 = 0.999（二阶动量）
  • lr = 0.001（学习率）
  • ε = 1e-8（数值稳定）

优点：

  • 自适应学习率
  • 适合稀疏梯度
  • 收敛快

缺点：

  • 可能不收敛到最优解
  • 泛化能力不如SGD

4. AdamW⭐Transformer标配

优点：

  • 解耦权重衰减
  • 更好的泛化
  • 大模型训练标准选择

5. AdaGrad

特点：

  • 学习率单调递减
  • 适合稀疏数据
  • 可能过早停止学习

6. RMSprop

特点：

  • 解决AdaGrad学习率递减过快
  • RNN训练常用

选择建议

任务类型 推荐优化器 原因
Transformer/LLM AdamW 大模型标准
CNN图像分类 SGD+Momentum 更好泛化
RNN/LSTM Adam/RMSprop 处理梯度变化
稀疏数据 AdaGrad 自适应稀疏特征

七、正则化技术⭐⭐⭐

1. L1正则化 (Lasso)

效果：

  • 产生稀疏解（部分权重为0）
  • 特征选择作用

2. L2正则化 (Ridge/Weight Decay)

效果：

  • 权重趋向于小值
  • 防止过拟合
  • 深度学习最常用

3. Dropout

超参数：

  • p = 0.5（全连接层常用）
  • p = 0.1-0.2（卷积层）

效果：

  • 防止神经元共适应
  • 相当于集成学习

4. Batch Normalization

效果：

  • 加速训练
  • 允许更大学习率
  • 轻微正则化作用

5. Layer Normalization

特点：

  • 对batch size不敏感
  • Transformer标配

6. Data Augmentation

  • 图像：旋转、翻转、裁剪、颜色变换
  • 文本：同义词替换、回译、随机插入删除
  • 最有效的正则化方法

八、损失函数⭐⭐⭐⭐

1. MSE (均方误差) - 回归

特点：

  • 对异常值敏感
  • 可导性好

2. MAE (平均绝对误差) - 回归

特点：

  • 对异常值鲁棒
  • 0点不可导

3. Cross-Entropy - 分类⭐最常用

特点：

  • 与Softmax配合
  • 梯度性质好

4. Focal Loss - 类别不平衡

超参数：

  • γ = 2（聚焦参数）
  • α = 0.25（平衡因子）

效果：

  • 降低易分类样本权重
  • 关注难样本

5. Contrastive Loss - 对比学习

应用：

  • 人脸识别
  • 图像检索

6. Triplet Loss - 度量学习

三元组：

  • anchor（锚点）
  • positive（正样本）
  • negative（负样本）

九、梯度问题⭐⭐⭐

1. 梯度消失

原因：

  • Sigmoid/Tanh的饱和区梯度接近0
  • 深层网络反向传播链式求导，梯度连乘趋于0

解决：

  • 使用ReLU激活函数
  • Batch Normalization
  • 残差连接（ResNet）
  • LSTM的门控机制

2. 梯度爆炸

原因：

  • 权重初始化过大
  • 学习率过大
  • 深层网络梯度连乘趋于无穷

解决：

  • 梯度裁剪（Gradient Clipping）
  • 权重正则化
  • 降低学习率
  • Batch Normalization

十、模型评估指标⭐⭐⭐

分类任务

混淆矩阵

准确率 (Accuracy)

精确率 (Precision)

含义：预测为正的样本中，真正为正的比例

召回率 (Recall/Sensitivity)

含义：实际为正的样本中，被正确预测的比例

F1 Score

精确率和召回率的调和平均

ROC-AUC

  • ROC曲线：TPR vs FPR
  • AUC：曲线下面积，越接近1越好
  • 适合类别不平衡

回归任务

R² (决定系数)

值域：(-∞, 1]，越接近1越好

十一、经典问题快速问答

Q1: 为什么要做特征归一化？

  • 加速梯度下降收敛
  • 避免某些特征主导训练
  • 提高数值稳定性

Q2: Batch Size如何选择？

  • 小batch（32-64）：泛化好，但训练慢，噪声大
  • 大batch（256-1024）：训练快，但泛化差，需调整学习率
  • 权衡GPU利用率和泛化能力

Q3: 过拟合的表现和解决？

表现： 训练集准确率高，验证集准确率低
解决：

  • 增加数据（最有效）
  • Dropout、L2正则化
  • 数据增强
  • Early Stopping
  • 减小模型复杂度

Q4: 为什么Transformer要用√d_k缩放？

  • QK^T后方差变为d_k倍
  • 不缩放会导致softmax进入饱和区
  • 梯度变小，训练困难

Q5: Adam和SGD如何选择？

  • Adam：快速原型、NLP、收敛速度优先
  • SGD+Momentum：图像分类、泛化能力优先
  • 实践中先用Adam快速验证，再用SGD精调

Q6: 为什么BERT用[CLS]token？

  • 聚合整个句子信息
  • 通过Self-Attention与所有token交互
  • 作为句子级别表示

Q7: 什么是Teacher Forcing？

  • RNN训练时，用真实标签作为下一步输入
  • 而不是模型预测结果
  • 加速训练，但训练测试不一致

Q8: Attention中Q、K、V的含义？

  • Query：询问”我要找什么”
  • Key：回答”我是什么”
  • Value：提供”我的内容是什么”
  • 通过Q·K计算相似度，用于加权V
