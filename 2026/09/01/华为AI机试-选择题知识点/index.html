一、激活函数（高频考点⭐⭐⭐⭐⭐）

为什么需要激活函数？
如果没有激活函数，多层神经网络就是多个线性变换的叠加，最终还是线性变换。激活函数引入非线性，使网络能够拟合复杂函数。

1. ReLU（Rectified Linear Unit）⭐⭐⭐⭐⭐

数学定义：

深度解析：

ReLU是2012年AlexNet使用后开始流行的激活函数，现在是深度学习的默认选择。

为什么ReLU缓解梯度消失？

  • Sigmoid在x很大或很小时，梯度接近0（饱和）
  • ReLU在正区域梯度恒为1，不会饱和
  • 反向传播时梯度不会衰减（正区域）

稀疏性的好处：

  • 假设50%神经元输出0，相当于网络”自动剪枝”
  • 减少神经元共适应，提升泛化能力
  • 计算更高效（跳过0值）

优点：

  • ✅ 计算极简：只需比较和赋值，无指数/对数运算
  • ✅ 训练速度比Sigmoid快6倍（Krizhevsky 2012）
  • ✅ 缓解梯度消失问题
  • ✅ 引入稀疏性（部分神经元输出0）
  • ✅ 更符合生物神经元特性（单侧抑制）

缺点：

  • ❌ Dead ReLU问题：负值输入导致梯度为0，神经元”死亡”
  • ❌ 输出不以0为中心（mean > 0），可能导致zigzag收敛
  • ❌ 输出无上界，可能导致数值不稳定

应对Dead ReLU：

  1. 使用较小的学习率（如0.01而非0.1）
  2. 使用Leaky ReLU变体
  3. He初始化：W ~ N(0, sqrt(2/n_in))
  4. Batch Normalization：保持输入分布稳定
  5. 避免大的负bias初始化

常见陷阱题 ⚠️：

❓ 题目1：ReLU的输出范围是？

  • A. (-1, 1)
  • B. (0, 1)
  • C. [0, +∞) ✅
  • D. (-∞, +∞)

💡 解析：ReLU负值输出0，正值保持原样，所以是[0, +∞)

❓ 题目2：使用ReLU时，发现训练到一半损失不再下降，可能原因？

  • A. 学习率过大导致大量神经元死亡 ✅
  • B. 数据量太少
  • C. ReLU不适合该任务
  • D. 需要更多层

💡 解析：学习率过大 → 权重剧烈更新 → 激活值变负 → 梯度为0 → 神经元死亡 → 损失卡住

❓ 题目3：以下哪个不是ReLU的优点？

  • A. 计算简单
  • B. 缓解梯度消失
  • C. 输出以0为中心 ✅
  • D. 训练速度快

💡 解析：ReLU输出[0,+∞)，均值>0，不以0为中心。Tanh的输出(-1,1)才以0为中心。

记忆技巧 🧠：

  • ReLU = “如来留” → 正值如来，负值不留
  • Dead ReLU = “学习太快死得快” → 学习率大导致神经元死亡

2. Leaky ReLU（泄漏ReLU）⭐⭐⭐⭐

数学定义：

直观理解：

  • ReLU：负值直接砍成0（斩草除根）
  • Leaky ReLU：负值保留一点点（留一线生机）
  • 就像给”死亡神经元”装了个”心脏起搏器”

为什么能解决Dead ReLU？

即使输入为负，梯度仍然是0.01，神经元不会完全”死亡”。

优点：

  • ✅ 解决Dead ReLU问题（负值有小梯度0.01）
  • ✅ 保留ReLU的计算优势（只多一次乘法）
  • ✅ 实践中通常比ReLU效果稍好
  • ✅ 输出可以为负，均值更接近0

缺点：

  • ❌ α需要手动设置（虽然0.01通常够用）
  • ❌ 不同任务最优α可能不同

常见陷阱题 ⚠️：

❓ 题目：Leaky ReLU的α通常设为多少？

  • A. 0.001
  • B. 0.01 ✅
  • C. 0.1
  • D. 0.5

💡 解析：α=0.01是最常用的值。太小（0.001）效果接近ReLU，太大（0.1）会破坏ReLU特性。

记忆技巧 🧠：

  • Leaky = “漏一点” → 负值”漏”出来0.01的梯度
  • α=0.01 → “01”倒过来还是”01”（回文数好记）

4. ELU（Exponential Linear Unit）⭐⭐⭐

数学定义：

直观理解：

  • 正值：和ReLU一样保持原样
  • 负值：指数衰减，有下界-α
  • 就像”软着陆”，不是直接砍到0

为什么输出均值接近0？

输出均值接近0 → 类似Batch Normalization效果 → 加速收敛

负值饱和的好处：

优点：

  • ✅ 输出均值接近0，加速收敛（比ReLU快）
  • ✅ 负值饱和区域产生对噪声的鲁棒性
  • ✅ 不会有Dead ReLU问题
  • ✅ 实验表明分类准确率通常高于ReLU

缺点：

  • ❌ 计算exp较慢（比ReLU慢约5倍）
  • ❌ 负值区域计算复杂
  • ❌ 实际应用较少（性价比不如ReLU）

常见陷阱题 ⚠️：

❓ 题目：ELU的输出范围是？

  • A. [0, +∞)
  • B. (-1, +∞)
  • C. [-1, +∞) ✅（假设α=1）
  • D. (-∞, +∞)

💡 解析：当x→-∞时，e^x→0，所以f(x)→α(0-1)=-α=-1

❓ 题目：ELU相比ReLU的主要优势？

  • A. 计算速度快
  • B. 输出均值接近0 ✅
  • C. 实现简单
  • D. 参数量少

💡 解析：ELU的核心优势是输出均值接近0，其他都不如ReLU。

记忆技巧 🧠：

  • ELU = Exponential（指数） → 负值用e^x
  • 有下界-α → “触底反弹”不会无限负

为什么Transformer用GELU？

  • B. 0.5

❓ 题目：Sigmoid(0)等于？

  • A. 0
  • B. 0.5 ✅
  • C. 1
  • D. undefined

💡 解析：f(0) = 1/(1+e^0) = 1/2 = 0.5

记忆技巧 🧠：

  • Sigmoid = “挤压函数” → 把任意值挤压到(0,1)
  • 导数 = 自己乘自己的补 → f’(x) = f(x)(1-f(x))
  • 梯度最大0.25 → “四分之一”，记住这个数
  • 深层网络的噩梦 → 梯度消失克星

为什么叫”自门控”？

直观理解：

  • x < 0: 轻微负输出（不完全截断）
  • x = 0: 输出0

优点：

  • ✅ 非单调性（在x≈-1.5处有小dip）增加表达力

缺点：

  • ❌ 计算成本略高于ReLU（需要sigmoid）
  • ❌ 非单调性可能导致优化困难
  • ❌ 实际应用较少（ReLU仍是主流）

激活函数 公式 值域 梯度消失 计算复杂度 适用场景
ReLU max(0,x) [0,∞) ❌ 否 ⭐ 极快 CNN隐藏层（最常用）
Leaky ReLU max(0.01x,x) (-∞,∞) ❌ 否 ⭐ 极快 替代ReLU
PReLU max(αx,x) (-∞,∞) ❌ 否 ⭐ 快 追求精度的CNN
ELU x if x>0 else α(e^x-1) [-α,∞) ❌ 否 ⭐⭐⭐ 慢 对噪声鲁棒
GELU x*Φ(x) (-∞,∞) ❌ 否 ⭐⭐ 中 Transformer标配
Sigmoid 1/(1+e^(-x)) (0,1) ✅ 是 ⭐⭐⭐ 慢 二分类输出、LSTM门
Tanh (e^x-e^(-x))/(e^x+e^(-x)) (-1,1) ✅ 是 ⭐⭐⭐ 慢 RNN隐藏状态
Softmax e^xi/Σe^xj (0,1) ❌ 否 ⭐⭐⭐ 慢 多分类输出
Swish x*sigmoid(x) (-∞,∞) ❌ 否 ⭐⭐ 中 EfficientNet

选择建议：

  1. CNN隐藏层：ReLU（默认）或Leaky ReLU（更稳）
  2. Transformer：GELU（标配）
  3. RNN/LSTM：Tanh（隐藏状态）+ Sigmoid（门控）
  4. 二分类输出：Sigmoid
  5. 多分类输出：Softmax
  6. 追求极致性能：Swish或PReLU

常见错误组合 ⚠️：

  • ❌ CNN用Sigmoid隐藏层（梯度消失）
  • ❌ 多分类用Sigmoid输出（应该用Softmax）
  • ❌ Transformer用ReLU（现在都用GELU）
  • ❌ 二分类用Softmax（太重，Sigmoid就够）

  • 陷阱：O(n²)或O(nd²)

优化器类

❓ Adam的默认β1和β2？

  • 答案：0.9和0.999
  • 陷阱：0.99和0.999

❓ AdamW和Adam的区别？

  • 答案：权重衰减方式（解耦vs耦合）
  • 陷阱：学习率或收敛速度

评估指标类

❓ F1是什么平均？

  • 答案：调和平均
  • 陷阱：算术平均或几何平均

❓ R²的取值范围？

  • 答案：(-∞, 1]
  • 陷阱：[0, 1]

损失函数类

❓ 为什么分类不用MSE？

  • 答案：与Sigmoid配合梯度消失
  • 陷阱：计算慢或精度低

❓ CrossEntropyLoss的输入是？

  • 答案：原始logits（未softmax）
  • 陷阱：softmax后的概率

数值计算类

❓ 卷积输出尺寸公式？

  • 答案：(N - K + 2P)/S + 1
  • 陷阱：忘记+1或/S

❓ LLaMA-7B用INT4量化后大小？

  • 答案：约3.5GB
  • 陷阱：7GB或1.75GB
